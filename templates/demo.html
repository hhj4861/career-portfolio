가상 데이터로 만든 설명용 데모 · 실제 회사 시스템의 복제가 아닙니다. 실제 AI·MCP·DB·Jira에 연결하지 않습니다. 결과는 미리 정한 예시이며, 상태는 이 페이지 안에서만 유지됩니다.

실제 구조에서 데모가 보여주는 범위
  • 로컬은 사용자가 명시적으로 요청합니다. 코드를 편집하거나 커밋했다는 이유만으로 검수를 시작하지 않습니다.
  • AI의 SQL 도출 결과와 Remote MCP 코어 판정은 다릅니다. 불확실한 SQL은 소스 보완이 필요합니다.
  • 개발자 질문과 DBA의 승인 전·실행 전 확인을 구분합니다. ‘승인합니다’라는 말로 업무 근거를 대신하지 않습니다.
  • DDL은 코딩 가이드, DML은 최신 검수의 티켓 미리보기와 생성 동의로 이어집니다. PR 검수는 별도 실행이며 이전 로컬 PASS를 복사하지 않습니다.
