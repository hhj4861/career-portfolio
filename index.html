01 / SOCAR · AI 업무 자동화

DBQ · AI 기반 DB 변경 검수

AI의 코드 해석과 결정적 SSOT 판정을 분리

시범 운영 준비

2026.08–현재 · 시범 운영 준비
Go · MCP(OAuth) · Claude Code · Helm · Terraform · GitHub Actions

업무 흐름 체험 ↓

문제

DB 변경 요청이 DBA와 여러 차례 왕복하며, 코드 변경·업무 의도·표준 근거가 분리되는 문제를 줄여야 했습니다.

내 역할

단독 설계·개발: 판정 코어, AI 인터뷰, SSOT·DBA 검토함, Remote MCP, 배포 인프라

접근·구현

AI가 SQL·ORM 변경에서 검수할 SQL과 맥락을 정리하고, Remote MCP의 Go 코어가 게시 SSOT로 판정하도록 분리했습니다. 개발자가 같은 대화에서 업무 의미를 답하면 새 검수 ID로 재검수하며, DDL은 코딩 가이드로, DML은 티켓 미리보기·명시 동의로 연결합니다. PR에서는 고정 스냅샷으로 DB 변경을 선체크하고 SQL 도출·SSOT 검수·1차 개발자/2차 DBA 보고서를 연결합니다.

결과·상태

Helm·Terraform·GitHub Actions로 배포 인프라를 구성하고 ORM 9종 대상 E2E 검증을 마쳤습니다. 현재 시범 운영을 준비하고 있으며, 운영 효과는 시범 운영 이후 측정할 범위입니다.

시범 운영 준비 단계입니다. 데모는 공개용 가상 입력으로 로컬·PR 검수의 책임 분리를 재구성하며 실제 DBQ에 연결하지 않습니다.
