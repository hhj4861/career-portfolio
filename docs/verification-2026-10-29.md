# 포트폴리오 · DBQ 흐름과 업무 데모 확장

- 기존 DBQ 승인 중심 예시를 명시적 로컬 검수와 PR 검수의 설명용 워크벤치로 교체했습니다.
- 최신 공식 DBQ 로컬 검수 안내, Remote MCP 스킬, CI 검수 지침을 대조했습니다. 비공개 원문·주소·업무 SQL은 공개 저장소에 복사하지 않았습니다.
- AI의 변경 해석, 게시 SSOT에 따른 코어 판정, 개발자 업무 확인, DBA 승인·실행의 책임을 구분합니다. 로컬 검수와 PR 검수는 별도이며 이전 PASS를 복사하지 않습니다.
- DDL 코딩 가이드, DML 티켓 미리보기·생성 동의, 동적 SQL의 소스 보완, DB 변경 없음의 선체크 생략을 가상 입력으로 설명합니다.
- QA 요구사항·TC·교차 검토·웹/모바일 실행·실패 후 재시도, 배포 필수값·티켓·중복 검증, 공통 로그·trace 연결의 별도 데모를 추가했습니다.
- 모든 데모는 브라우저 메모리의 고정 가상 결과입니다. 실제 모델·MCP·DB·Jira·Slack 호출, SQL 실행, 회사 운영 시스템 재현은 없습니다.
- 이력서 7개 회사·23개 프로젝트를 보존하고 최근 DBQ·QA·배포 검증의 과제·책임, 구현, 검증·현재 상태를 구체화했습니다. 확인되지 않은 성과 수치를 추가하지 않았습니다.

- `node scripts/test_demo_state.cjs`: 25개 판단 규칙 검사 통과.
